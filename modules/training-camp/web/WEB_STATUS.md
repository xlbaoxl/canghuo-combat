## 保存与发布边界

保存仍由原控制器写入原设置文件。网页只回查 Godot 现有 IndexedDB 文件，回执有序号，旧回执不会覆盖新保存；保存中、已保存、失败有独立提示。测试不再固定等待两秒就刷新，而是确认输入已接受、实际存储字节一致，然后连续三轮更换人物/成长并立即刷新。

九项 Node 正反例覆盖延迟、旧回执、超时、失败恢复、显式写入失败、数据库缺失、接口不支持、只读事务与数据库删除竞争。不新增存档数据库、不复制战斗规则。存储确认依赖桌面浏览器的 IndexedDB 枚举与固定 Godot 4.7.2 IDBFS 文件结构；不支持或超时明确标记未确认。强制退出、清理数据、配额和隐私模式仍可能造成丢失；运行中战斗不续接。

发布仍要求正确提交/干净源码、真实规则和浏览器检查通过、全部文件指纹匹配、合法运行文件白名单以及专用托管项目的完整访问保护；缺少凭据、保护、成功证据或文件校验任一条件都会拦截。不创建托管项目、不关闭访问保护、不把代码或设计文档当运行包上传。
