## 真实产物与体积

首轮 release 的 `index.pck` 为 36,035,680 字节，`index.wasm` 为 38,820,072 字节。工程可以输出实际浏览器可加载文件，不是静态界面原型。其余 JS/HTML/图标及各文件 SHA256 保存在每次 `build.json` 中；必须对应实际运行提交，不沿用旧报告宣称新提交已经验证。
