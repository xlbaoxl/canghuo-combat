## 真实产物与体积

首轮 release 的 `index.pck` 为 36,035,680 字节，`index.wasm` 为 38,820,072 字节。工程可以输出实际浏览器可加载文件，不是静态界面原型。其余 JS/HTML/图标及各文件 SHA256 保存在每次 `build.json` 中；必须对应实际运行提交，不沿用旧报告宣称新提交已经验证。

## 尚未完成

保护托管账号的连接与首次部署；实际 HTTPS 网址的登录、响应头与完整对局检查；作者亲自试玩；Safari/Firefox/手机及其他 GPU 路径；云存档；完整可验证重放与线上自动反馈归档。复制摘要、全屏和更新提示已实现，但尚未分别做交互验收。没有已部署网址时不提供猜测链接。

保存确认依赖桌面浏览器可枚举当前源的 IndexedDB 数据库以及固定 Godot 4.7.2 的 IDBFS 文件结构；接口不可用、读回失败或超时会明确显示未确认，绝不创建第二份存档冒充原存储成功。浏览器强制退出、清理数据、配额与隐私模式仍可能导致丢失；当前对局不会作为运行态续接。

证据归档在对应 Actions 的 `web-verification`。失败产物明确名为 `web-unverified-candidate`；不会上传成已验收可玩版本。公开或稳定部署必须同时满足真实规则和浏览器测试，并完成专用项目的全部部署访问保护检查。
