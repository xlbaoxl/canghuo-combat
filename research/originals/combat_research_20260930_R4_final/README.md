# 四款游戏战斗系统研究｜最终交付

2026-09-30 · 第四轮收官 · 研究框架 v2-R4-final

四轮研究完成。最终稿将前三轮材料统一成四份案例和逐题横向结论，覆盖觅长生、圣兽之王、弈仙牌、太吾绘卷的同一套D01–D16问题。正文无需对照历轮报告才能阅读。

最值得带入策划考量的结论是：比较一个机制时，须同时看它让玩家在何时作什么决定、为此承担哪一层成本、靠哪些配套才能兑现。技能多、操作多、自动执行或提供预览，都不能单独证明决策深度或体验质量。

## 阅读顺序

1. [最终横向报告](comparison.md)：层次/术语映射、16题共同矩阵、逐题解法/条件/代价与整体依赖。
2. [八条条件结论与选择指南](design_principles.md)：每条包含四作证据、收益、条件、成本、失效情形与评审问题。
3. 按需阅读统一案例：[觅长生](cases/觅长生.md)、[圣兽之王](cases/圣兽之王.md)、[弈仙牌](cases/弈仙牌.md)、[太吾绘卷](cases/太吾绘卷.md)。每份都有完整流程、贯通片段、16维解释及阶段压力对照。
4. [结论边界与收官记录](closure.md)：版本限制、争议定案、机制修订和最终未知。

## 范围和使用方法

机制事实、公开作者体验和研究推论分层表达。第三轮起采用用户选择的网络评论路线；没有本研究的原作战斗实测。此前觅长生曾进行菜单/存档选择界面的启动准备，具体边界在收官记录中披露。

现有本地材料包括发行程序集的反编译表示、配置、安装镜像和日志等，各作可读深度不同，不能统称完整源码。源文件指纹是先前读取时的定位依据；本轮核对复制和归档沿革，不声称重新哈希所有商业游戏原件。

本包不含商业程序、资源、反编译代码、存档或网页全文。第三轮来源短引文保留在证据资料中用于定位，当前综合为原创转述。data中的R2/R3历史资料保留原指纹，可能含当轮的后续核查设想；最终措辞及任务状态以本轮正文和审计为准。

此次完成比较研究，没有把案例机制写入《藏火》正式设计或代码，没有另起第五轮任务。前三轮原交付保持不变。

如需复核包结构，在解压目录运行：`python tools/validate_research.py`。该脚本只读研究文件并写研究验证记录，不操作游戏、不访问网络；历史ZIP和复制沿革的核查结果另见provenance_R4.json。
