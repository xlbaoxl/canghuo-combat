# 逸剑风云决出手频率与技能冷却机制研究报告

本报告面向战斗策划，汇总《逸剑风云决》的行动调度、集气属性、技能冷却及两者的关联，回答角色为何能比对手多次行动，以及行动优势如何影响技能释放频率。

核心机制是：**集气决定何时获得行动机会；角色自己的回合结束，推进自己的技能冷却。** 提高集气速度能增加行动机会，并让技能更快走完冷却所需的自身回合。基础集气速度的派生项来自内功，技能基础 CD 来自技能表。

核查日期：2026 年 9 月 30 日。适用版本：Steam Build 21798996。依据为本地发行程序的选择性静态反汇编，以及同版本配置与蓝图；未取得开发者完整源码工程，未进行实战计时。下文将程序与配置事实、条件推算、策划分析分别说明。

## 出手权如何产生

### 集气达到门槛后进入行动调度

在角色存活、当前不处于活动回合且通过状态检查的累积路径中，程序执行：

```text
新增集气值 = 本次允许累积的逻辑时间 × 有效集气速度
当前集气值 += 新增集气值
当前集气值达到 1000 → 返回就绪，交由调度系统处理
```

因此，出手先后来自各角色的集气进度。速度更高或获得额外集气的角色，可以更早再次就绪，在对手两次行动之间获得多个行动机会。某个短时间段是否连续行动，还取决于双方当时的进度、状态和执行队列。

这里的时间是程序用于集气推进的**逻辑时间**。回合模式、即时模式的完整时钟推进、动画占用和队列尚未全部核准，不能把 `1000 ÷ 集气速度` 直接宣称为现实中的等待秒数。

### 行动结束后如何重新起跑

已核查的行动结束逻辑为：

```text
当前集气值 = 行动后预留集气值
行动后预留集气值 = 0
```

当预留值为 0 时，下一次从 0 开始集气；有预留时，从该值继续补到 1000。因此，不能把这套逻辑统一解释为“达到门槛后减去 1000，并自动保留全部溢出”。额外集气与预留集气应按各自效果区分。

## 哪些因素影响行动频率

### 内功决定基础派生项

对正常的正内功输入，在没有其他修饰时：

```text
派生集气速度 = 70 × log2(内功)
集气速度 = 基础集气速度 + 70 × log2(内功)
```

原生计算实际使用 `logf(NeiLi) × 1.4426950216293335 × 70`，对应上述以 2 为底的对数形式。

**内功每翻倍，派生集气速度增加 70。** 这会产生递减的相对收益：内功越来越高时，同样翻倍所增加的 70，占原有总速度的比例越来越小。

基础集气速度属于角色配置。已抽查的常规模板子集多为 30，主角配置行的基础值为 80；不能把 30 当成全角色固定常数。最终生效属性还可能受到初始化倍率、成长和效果影响。

身法在另一个已读计算类中参与行动力派生：`(0.4 × 身法)^0.2 + 2`。这说明两项属性在程序上有独立计算路径；行动力的所有移动、消耗和行动资格用途未穷尽，本报告不将它等同于出手次数。

### 装备 经脉与战斗效果

| 影响途径 | 已有证据或例子 | 对频率的解释 |
| --- | --- | --- |
| 基础内功变化 | 内功进入对数派生公式 | 改变基础集气速度，收益按对数增长 |
| 直接增加集气速度 | 虎头佩固有集气 +20；和氏璧 +220；云纹太极图 +210 | 改变速度数值；随机词条和其他效果需另外计入 |
| 经脉属性与触发效果 | 配置中有直接增加集气、暴击后获得集气等效果 | 持续增速与条件触发加条应分开评价 |
| 百分比集气效果 | 已读 `GE_JiQi+25` 捕获 `TurnRate` 的基础值并使用 0.25 系数 | 不能统一假设所有百分比都乘最终面板，也不能一概连乘 |
| 轻功后的下一回合集气 | 基础轻功、武当轻功文本为每级下回合集气 +5%，10 级 +50%；对应效果配置有 50 至 500 的数列 | 改变后续某次集气过程，不等于永久提高同百分比速度；施放轻功本身也占用行动 |
| 控制与执行条件 | 集气路径存在存活、状态和回合条件检查 | 影响能够累积或执行行动的机会；具体控制效果需逐项判断 |

轻功示例的技能文本、蓝图引用与效果数列相互对应；蓝图中效果等级参数 0 如何映射实际等级的原生桥接，尚未独立追完。它可作为配置层证据，不作为已实测的永久频率增益。

## 正常情况下出手比率有多大

### 比率由条件决定

在双方采用相同门槛、每次结束后回到 0、速度保持不变、可集气时间窗口相同，且无控制、额外回条、控制和执行差异时，可作长程近似：

```text
A 的行动次数 ÷ B 的行动次数 ≈ A 的有效集气速度 ÷ B 的有效集气速度
```

这描述足够长的共同集气逻辑时间内的趋势，不保证短时间内严格按某种顺序轮流出手。若只估算某次下一行动，并已知预留集气值 q：

```text
下一次集气等待量 ≈ (1000 − q) ÷ 有效集气速度
```

该式适用于尚需补气的情况。一次性返条不能直接当成每次都发生的长期收益。

### 受控内功算例

下表统一假设基础集气速度为 30，并排除装备、经脉、状态和额外集气。数值是公式推算。

| 内功 | 计算后的集气速度 | 相对内功 100 的行动频率 |
| --- | ---: | ---: |
| 50 | 425.07 | 0.859 倍 |
| 100 | 495.07 | 1.000 倍 |
| 200 | 565.07 | 1.141 倍 |
| 400 | 635.07 | 1.283 倍 |

在这个算例中，内功从 100 提升至 200，行动频率约增加 14.1%；提升至 400，约增加 28.3%。仅凭内功翻倍，不能推出出手次数翻倍。

### 受控装备算例

同样采用内功 100、基础集气速度 30，仅替换饰品的固有集气项：

| 饰品 | 固有集气加值 | 计算后的集气速度 |
| --- | ---: | ---: |
| 虎头佩 | +20 | 515.07 |
| 和氏璧 | +220 | 715.07 |

在前述条件下，后者相对前者的行动频率约为 `715.07 ÷ 515.07 = 1.388`，即约高 38.8%。这里未计随机词条、其他装备、武学和状态。

以上解释了速度差如何转化为行动差，但现有材料不足以给出“全游戏正常战斗通常为 1.2∶1”这样的总体统计。NPC 表包含剧情阶段重复配置、特殊兵种和测试记录，直接对全表求平均不能代表玩家的实际遭遇。

## 技能 CD 如何计算

### 冷却以本人回合结束为单位

技能基础冷却从技能表 `Skills.Duration` 直接读取。冷却效果使用 `TurnBased` 计时：角色自己的回合结束时，其能力系统回合计数增加 1，然后检查本人效果是否到期。

基础 CD 计算函数没有直接使用身法、内功或集气速度，也没有统一随技能等级递减的公式。等级可以通过某个技能专门配置的效果减 CD。

普通冷却的内部到期判断可写为：

```text
冷却起算计数 + 冷却长度 ≤ 本人当前回合计数 → 冷却到期
```

施加冷却后，程序对长度大于等于 1 的技能，将起算计数向后平移 1，以抵消施放当次回合结束的推进。于是，对普通整数 CD 为 D 的技能：**施放当次结束仍剩 D，随后本人每结束一个回合减少 1。**

### 三回合冷却的完整时间线

以下按普通施放流程重构，假设没有减 CD、重置、追加行动或其他特殊结算：

| 本人的回合 | 本回合能否使用该技能 | 本回合结束后的冷却 |
| --- | --- | ---: |
| 第 1 回合 | 首次释放 | 3 |
| 第 2 回合 | 冷却中，使用其他行动 | 2 |
| 第 3 回合 | 冷却中 | 1 |
| 第 4 回合 | 本回合开始时仍在冷却 | 0 |
| 第 5 回合 | 可以再次释放 | 若释放则重新计数 |

因此，“CD 为 3”与“每 3 次自身行动就能放一次”需要区分。此例两次施放的回合编号为 1 和 5，相差 **4 个自身行动周期**。其他角色行动不会直接增加这个角色的冷却计数；连击段数和反击次数也不能自动当作额外自身回合。

| 基础剑法 | 一式 | 0.5 | 当次回合结束清除，下次自身行动即可再用 |
| 江湖剑法 | 二式 | 1 | 施放后再完成 1 个自身回合 |
| 碧水剑法 | 三式 | 2 | 施放后再完成 2 个自身回合 |
| 达摩剑法 | 绝式 | 4 | 施放后再完成 4 个自身回合，未计 10 级效果 |
| 基础轻功 | 轻功 | 2 | 施放后再完成 2 个自身回合 |
| 武当轻功 | 轻功 | 3 | 施放后再完成 3 个自身回合 |
| 天羽飞踪 | 轻功 | 6 | 施放后再完成 6 个自身回合，未计重置效果 |

一式常见的 `0.5` 是一个需要单独理解的配置值：因为小于 1，它没有起算平移补偿，所以在施放当次结束时即可到期。它不表示现实中的半秒，也不能套用普通整数 CD 的等待公式。

### 同类别共享冷却

程序根据技能表 `CDType` 选择冷却标签，施加与检查使用同一套类别。类别 1 至 6 分别对应一式、二式、三式、绝式、轻功、心法。

**同一角色上，同 CDType 的技能共享该类冷却状态。** 不同类别分别管理，同类别的技能仍然可以配置不同的冷却长度。这个结论来自冷却标签逻辑，不额外推定所有场合都允许战中切换装备技能。

### 直接改变冷却的效果

| 效果 | 已核查配置 | 解释 |
| --- | --- | --- |
| 达摩剑法 10 级 | 技能结束前，对绝式类别冷却 −1 | 基础 4 回合通常变为 3 回合 |
| 天羽飞踪 10 级 | 技能结束前，50% 概率对轻功类别冷却 −10 | 文本称重置；对其基础 6 回合冷却足以清除。不能把它扩大为任意加长情况下都无条件清零 |
| 截脉 | 技能结束前，按本次技能的 CDType 为 2、3、4 分支，对相应类别冷却 +1，并移除一层截脉 | 多层截脉提供多次触发机会；不能解释为一次施放按全部层数增加 CD |

这里的“回合推进”“减冷却”“重置冷却”是不同来源的变化，应分别计入技能循环。

## 两套机制如何共同影响技能频率

### 集气速度控制行动周期 CD 控制技能占用的周期数

对普通整数 CD 为 D 且 D ≥ 1 的技能，若每次都在冷却完成后的最早机会释放、每轮至多释放一次该技能、不改用同类别其他技能占用冷却，并排除重置、额外回条、控制、资源不足和执行时间差异，可由上述规则推导：

```text
理想情况下，两次施放间隔 = D + 1 个自身行动周期
技能释放频率 ≈ 自身行动频率 ÷ (D + 1)
```

再采用“每次从 0 开始集气”的理想模型，可写为：

```text
技能释放频率 ≈ 有效集气速度 ÷ [1000 × (D + 1)]
```

这里的频率以共同集气逻辑时间为基准。这是用于策划比较的推导模型，不是程序中已找到的独立公式，也不是每分钟实测释放次数。

### 速度收益不能重复相乘

假设两名角色使用相同 CD 的技能，A 的行动频率是 B 的 1.2 倍。在上述理想条件下，A 的该技能释放频率也约为 B 的 1.2 倍。

“行动更频繁”和“更快走完自身冷却回合”描述了同一行动时钟的两个结果，不能把两者再相乘成 `1.2 × 1.2 = 1.44`。如果另有独立的减 CD 效果，才需要另算技能循环收益。

例如，普通 CD 从 4 降到 3，两次施放间隔从 5 个自身周期降为 4 个。在冷却转好即释放的理想循环中，释放频率提高 `5 ÷ 4 − 1 = 25%`。再叠加独立的 20% 行动频率提升，相对原方案的理想技能频率为 `1.2 × 5 ÷ 4 = 1.5`，即提高 50%。这些收益成立的前提是资源、目标与施放条件允许。

### 对战斗策划的含义

**内功成长决定平缓的基础速度差。** 对数公式使单纯堆内功的边际收益递减；装备固有集气、百分比效果、一次性加条和控制，需要结合各自的作用基数和触发频率单独比较。

**自己的回合也是技能循环的时钟。** 提高行动频率会增加普攻、移动或其他行动机会，也会提高冷却技能的长期可用频率。评价速度属性时，需要观察整套技能轮换，而非只统计普通攻击次数。

**共享类别限制了同类武学轮流绕过冷却的空间。** 它把循环选择更多放到不同类别之间；某类减 CD 或重置效果，也会直接影响这一类的可用性。

**一次性返条必须计入施放成本。** 为加快下一次行动而使用轻功，本次行动已经被占用，且轻功自身还受 CD 限制。下一次更快，并不自动说明长期输出同幅度提高。
