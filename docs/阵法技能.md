# 阵法技能：布阵、成阵与持阵

> 1.1｜2026-10-10｜状态：核心细则已由作者明确，**尚未进入3.0.1执行器**。
> 本文更新已有专题，不另建一套规则。区分已确定规则、实施默认、试验参数与待设计内容；来源为本会话。

## 1. 作者构想与本轮定案

阵法是不同于普通技能的功法类型。使用布阵后进入等待，等待结束才出现阵法效果；随后同一个技能入口转为持阵。各阶段有独立费用和不同的等待/回转。

龟甲阵已确定：

| 项目 | 现行设计要求 |
|---|---|
| 布阵 | 等待3个全部自身窗口，未成阵时没有返盾效果 |
| 成阵后阵势 | 受到直接伤害后，仅按实际气血损失的50%获得护体 |
| 持阵 | 主动使用时增加当前护体的50%，立即生效后进入CD1 |
| 时钟 | 普通与战机均计一次自身窗口W；窗口内施法次数不增加W |
| 费用结构 | 布阵与持阵分别定义灵气消耗；具体数值尚未给定 |
| 持续 | 无特殊说明时永久，不自然到期；当前训练营按本场持续理解 |
| 主动换走 | 未成阵时取消布阵，成阵后撤下阵势；均不退还已付灵气 |
| 重复 | 同名阵法不能叠加，不得重复注册多份收益 |

阵法用于长线投资。玩家付出前期行动、灵气、等待和占格，换取成型后的效率或长期效果；目标不是把普通技能加一个延迟，却保持所有后续收益完全相同。效果与费用仍需实际对照，不把设计目标宣称为已经平衡。

## 2. 为什么需要独立类型

普通技能：支付 → 立即执行效果 → 等待恢复使用资格。

阵法布置：支付 → 创建待成阵任务 → 到期自动激活阵势并转换入口。

持阵：支付 → 立即执行持阵效果 → 等待再次持阵。

延迟成阵与普通回转不是同一职责。不得全局增加“CD归零就执行技能效果”；不能为了凑CD3给布阵塞三句无关作用。布阵和持阵是不同时间的阶段，不等于同一次施法里的两条规则句。

对普通法继续CD=N；阵法模板单独声明成阵延迟，持阵自身按正常规则句/回转处理。

## 3. 状态机与已确定时钟

`未布阵 → 布阵中 → 已成阵/可持阵 ↔ 已成阵/持阵回转中 → 撤阵/失效`。

**已确定：**成阵延迟使用全部自身窗口W。W=1布阵，成阵窗口为1+3=4；W=2、3仍在等待，W=4开始的到期步骤自动成阵。布阵当窗不抵掉一个等待；普通与战机均推进一次W。

| 自身窗口 | 一个合法示例 | 阵法状态 |
|---|---|---|
| W=1 普通 | 主动布阵 | 登记W=4成阵，无返盾 |
| W=2 战机 | 使用其他合法能力，也可提前结束 | 只推进一次等待，不按出招数多减 |
| W=3 普通 | 正常行动 | 仍未成阵 |
| W=4 普通或战机 | 进入窗口，到期成阵 | 开始提供阵势，开放持阵 |

这是本人之后第3次出手机会，不是全场经过3个人物行动，也不是3个公共刻。战机相当于一次**全部自身窗口**，不等于普通周期计数R或公共刻t也增加；不因此多领自然回气、普通窗口法宝或蚀骨结算。

成阵本身不额外占主动作、不再推进W。持阵当窗可以使用，使用后ready=W+1。其执行节点沿用方案：窗口前存活检查 → W增加/本窗记录重置 → 到期任务 → 对应窗口开始效果 → 主动选择。不倒退保护窗口前已经发生的效果。

布阵不是连续引导。等待期间可以使用其他本领；布阵动作当次结束，只留下待办任务，不让原始施法调用栈跨多个回合悬挂。未来专用R时钟的阵法必须另外声明，不改变龟甲阵已选W规则。

## 4. 返盾：只按实际气血损失

**已确定：**返盾请求量为本次直接伤害结果中实际气血损失的50%，再按公共整数与护体上限规则提交。不包括护体吸收、未生效请求量或过量伤害；此前“包含护体吸收”的方案退出本阵现行候选，不再要求作者重复选择A/B。

例如，40护体承受100直接伤害，气血充足且结算后存活：吸收40、气血损失60，返盾请求30。完全由护体吸收时，气血损失0，返盾为0。

本次伤害先结算，存活者再获得护体；新增护体只保护后续攻击，不倒扣已发生伤害，不靠受伤后效果复活。气血支付不是伤害，公共效果伤害不是直接伤害。**沿用实施默认：只接受敌对来源，避免自伤刷盾；这是来源限制，不改变已定返盾基数。**

按每次独立伤害组的确定结果响应。同一阵势对同一事件最多一次；一击多个目标与多击同目标保持不同作用域。连续两击：第一击结果 → 合法返盾响应 → 第二击。阵势只提交新的护体请求，不自己实现扣血、防护和死亡算法。

## 5. 持阵、独立费用与承载边界

持阵效果组开始时读取自身当前护体，按50%请求增加护体，遵守公共整数取整和总池≤Hmax。40层变60层；0层仍为0。一次持阵只读取一次、增加一次，不反复读取增长后的结果。

当前护体已经含成长或其他效果，不默认再把派生量乘一次凝练/熟练。比例研究若开放，需要独立且明确的研究参数，不借通用成长再次放大。

**已确定：布阵费用与持阵费用独立定义。**主动布阵和主动持阵各按自己的当前费用核验、支付，并适用主动动作与状态规则；不把“独立费用”解释为同一动作先后付两次。自动成阵与受伤返盾不再支付主动费用，不二次扣撕裂或逆气的代价。

两个阶段的具体报价尚未给定，应在首批内容中分别填写并标试验值，不从CD或50%系数擅自反推为已定价格。独立参数允许分别调整，不要求一个费用由另一个费用机械派生。

**装配承载映射仍待确定。**作者本轮确认的是两个施放消耗，并未采用“费用相加”或“取较大值”的装配公式。成阵不增加第二个功法格；本法必须有稳定、可预览的装配检查方案，不能因阶段切换暗中变成非法配装。实现此项之前单独记录采用的试验口径。

持阵是主动强化，不是每回合不点就崩阵的维持税。默认永久不能被擅自改成持续扣气、每回合续阵或站桩引导；这些属于另一个需要明确采用的机制。

## 6. 持续、撤阵与实例清理

实例至少保存：definition/instance、所有者、保护对象、来源功法/格子、创建W、到期W、阶段、监听、依赖任务、版本及执行参数快照。

### 6.1 作者已确定

无特殊说明时，成阵后没有自然到期倒计时。此处“永久”是在当前独立遭遇内没有时长限制，不据此新增跨战保留，也不等于免疫一切失效。

主动把来源法门换走：未成阵则取消任务，已成阵则撤下阵势，均不退还已支付灵气。同名不能叠加；不能通过同源改名、版本或重复监听得到多份返盾。是否允许重新布阵刷新、异名多阵并存及多人覆盖，不能由“同名不叠加”自动推导，首版单人单阵样板不需要扩充这些机制。

### 6.2 与现有公共规则衔接的实施默认

- 换走不清除格子和同源尚未结束的等待；重新装入不能洗CD。
- 来源死亡、战斗结束或合法撤阵时，注销监听并取消依赖任务；到期时再核验来源仍有效。当前未加入复活/倒地继续维持规则，不预先创造这些例外。
- 撤阵不倒扣已经并入公共护体池的层数，不能误删其他功法或法宝贡献。
- 同名去重在当前单持阵者样板内成立；多人保护、敌我各有同名阵势等场景需要明确作用域，不实现为全场只能有一份同名阵的垄断规则。

新增定义与运行态进入版本化快照。初版可以只在安全决策边界保存；不支持的运行态续读应明确拒绝，不能读档后重复登记或直接跳过等待。允许读取的快照必须保留等待和实例状态，不能“图标没了但监听还在”。

## 7. 与战机、格子、法宝和AI的接口

布阵和持阵占普通主动作；战机按入口限制使用，不在同窗重复持阵。战机推进W能帮助提前成阵，是本轮已认可的奖励收益；取得战机的算法仍待完善，不因此否定W计数。

布阵时持阵入口不可用，成阵后仍使用原功法格。界面显示剩余自身窗口数、持续阵势、当前阶段费用及CD；不能把普通CD转好显示成自动再次持阵。

法宝依然自动＋独立《催》，阵法不是删除催动的理由。灵宠有自己的行动归属。伤害来源、返盾来源和护体获得者分别记录。

AI预演复制待成阵任务、阵势实例和阶段。不能只看布阵当下无伤害就认为无价值，也不能在有限观察没看到成阵时虚构确定的长期收益。应区分当前立即收益、已经承担的沉没成本、后续预期与截断边界；用公开信息对照，不读玩家未来输入。

## 8. 长线投资的验证目标

**作者明确的价值方向：**成型后在适用条件下，阵法能力应比相同灵气的普通能力具有更高效率，或在长回合战斗中体现更好的累计效果。前期布阵行动、灵气、等待、持续占格与换走损失，就是取得后续优势的成本。

比较不能只算持阵那一次：分别记录布阵费用与主动作、成阵时点、累计持阵次数/费用、返盾实际新增、持阵实际新增、护体溢出和真正挡住的伤害、阵势最终失效原因。生成护体和之后吸收伤害是不同指标，不能加在一起重复当作总收益；剩余未使用护体也不能冒充已经承伤贡献。

在同人物、同总投入/装配约束与相同敌人压力下，对照不布阵、早布阵、晚布阵以及中途换走。观察什么时候回本，而不是固定规定所有战斗都必须回本。短战来不及发挥、0盾持阵无收益是合法边界；普通能力仍保留立即见效、灵活换法和应急价值。

持阵50%是复利：无受击/费用/上限干扰时40→60→90→135。保留作者的50%样板，联合费用、行动和护体上限测试，不暗改倍率。返盾以损血为前提：护体越充分，后续实际损血可能越少，不能把返盾当成固定每窗免费收入。遇到效果伤害、先手压力和短长战应分别记录，不能只堆高敌人血量证明阵法有用。

单句、双句、三句法的相对价值按实际对照测试，不在纸面先定谁强。战机争夺另作机制讨论，阵法功能不等待全部战机数值定稿。
