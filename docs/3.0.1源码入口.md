## 工程与代码位置

导入 Godot 的文件是：

```text
modules/training-camp/project/project.godot
```

按[模块说明](../modules/training-camp/README.md)使用本工程配套的 Godot 4.7.2。工程内容如下：

| 位置（相对 `modules/training-camp/project/`） | 内容 |
|---|---|
| `project.godot`、`main.tscn` | 工程配置与主场景 |
| `scripts/battle.gd` | 战斗执行与结算 |
| `scripts/combat_protocol.gd` | 时钟、阶段与规则协议 |
| `scripts/effect_math.gd` | 效果数值计算 |
| `scripts/catalog.gd` | 内容编译、合法性校验、成长与开局快照 |
| `scripts/ai.gd` | 共用合法行动与执行器的 AI |
| `scripts/main.gd`、`scripts/ui/` | 训练营流程、界面与战斗操作 |
| `data/content.json` | 人物、功法、法宝、对手等内容数据 |
| `assets/` | 工程资源与来源、许可记录 |
| `tests/` | 规则、表现、线程与固定对局测试 |
| `export_presets.cfg` | 原桌面导出配置 |

模块层的[构建工具](../modules/training-camp/tools)、[操作说明](../modules/training-camp/PLAY_GUIDE.md)和[原版测试报告](../modules/training-camp/TEST_REPORT.md)继续保留在 `modules/training-camp/`。要取得整个源码快照，可在 `source/3.0.1` 分支页面使用 GitHub 的 Code → Download ZIP；解压后导入上面的工程文件。下载的是仓库源码快照，不是 Actions 中的网页运行包。

## 与网页版的区别

`3.0.1` 是原游戏模块版本；`3.0.1-web.2` 是同一游戏的浏览器适配版本。网页适配源码在 `modules/training-camp/web/`，构建、测试和 Pages 发布工具在 `tools/web/` 与 `.github/workflows/web-playtest.yml`。

旧 `web-playtest-site` 分支以及 Actions 的 `web-playable-release` 是编译后的网页资源入口，不能当作 Godot 源工程使用。本次源码入口不修改、重新打包或重新部署线上试玩版。
