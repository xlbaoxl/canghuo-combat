## 如何试玩与反馈

电脑浏览器打开上述入口，首次可能自动初始化刷新一次，完成后点击“进入训练营”。流程为选人 → 配装 → 镜像或预设对手 → 开战。1–4 选择技能，再点击目标确认；右键取消；空格结束窗口。页面显示实际版本与提交标识。

开战时保存本次配置到当前浏览器，等待“本次配置已保存”提示再刷新。刷新会结束当前对局，不续接战斗运行态，只恢复合法配置及冻结的重试初态。清理网站数据、隐私模式和更换域名可能丢失配置；不是云存档。

页面上方“反馈本场问题”可复制摘要或下载实际诊断，再将问题描述和记录带回讨论。诊断只在浏览器生成，不自动上传。完整 AI 指令重放尚未验证，不宣称诊断必然复现任何问题。

## 自动发布链路

`main 相关代码提交 → 原规则/表现/线程/固定对局 → 原浏览器回归 → Pages适配 → 无响应头子路径真实浏览器回归 → 同一产物发布GitHub Pages → 实际HTTPS完整对局验收`。

PR只构建与验证，不覆盖试玩站点；文档更新不自动重建游戏。构建或发布前验证失败时不执行部署。线上浏览器验证发生在部署之后，失败时不能宣称验收通过；当前流水线没有自动回滚，不把这一点伪装成已实现。页面发现更新只提示，由玩家决定何时重新载入，不在对局中自动换规则。
