# 网页托管连接：不依赖 ChatGPT 弹窗

## 作者只做一次的网页设置

不需要安装客户端、Godot、命令行或 ChatGPT 的 Vercel 插件，不需要下载工程，也不需要在聊天中提供密码、令牌或验证码。当前连接仍只有 GitHub；“插件可搜索”不等于作者的网页界面出现了授权卡片。

使用 Vercel 自己的 GitHub 集成。首次设置顺序如下，**先保护访问，再选择带游戏包的分支**。

1. 在 [Vercel 新建项目](https://vercel.com/new) 登录，使用能访问 `xlbaoxl/canghuo-combat` 的 GitHub 账号；如要求安装 Vercel GitHub App，只授权这个仓库即可。选择导入本仓，Framework Preset 为 Other，Root Directory 保留仓库根目录，不覆盖仓库里的 Build / Install / Output 设置。初次从 main 部署只显示“托管设置”页，不会发布游戏、策划或研究文件。
2. 在项目 Settings → Deployment Protection 启用 Vercel Authentication，选择 **All Deployments**，保存。仅 Standard Protection 不保护生产域名。私有源码仓库也不能替代网站访问保护。
3. 在项目设置的 Production Branch / Branch Tracking 中改为 `web-playtest-site`。保留仓库根目录与配置文件，不要把 Output Directory 手填为源码根目录或之前的占位目录。随后在 Deployments → Create Deployment 选择该分支并部署。该分支已有自己声明的 `public` 静态输出，不会在 Vercel 上重装引擎或重跑另一个版本。

首次完成后，将 **实际网址** 发回讨论，继续核对匿名访问保护、HTTPS、跨源隔离头、版本与完整战斗。不要发送登录 cookie、访问令牌或带有绕过保护密钥的链接。

Vercel 对私有仓库的提交作者有账号权限检查；同步提交保留真实源提交作者，以 GitHub Actions 为提交者并明确标注生成来源。应使用仓库作者关联的 GitHub 账号登录 Vercel。若平台要求不同团队权限或计费方案，先停止并报告，不自动开通付费或把仓库公开。

## 自动更新链路

`main 源码 → Web playtest → 真实规则与浏览器通过 → 校验同一构建的文件清单 → 私有 web-playtest-site 分支 → Vercel Git 部署`。

新增 `Sync verified Web site branch` 工作流仅处理本仓 main 的成功 Web 工作流；拒绝 PR、fork、错误工作流和失败结果，过时提交不替换新版本。运行文件白名单、原始构建清单、浏览器构建身份及全部文件哈希必须一致。同步不调用 Vercel API，不需要 `VERCEL_TOKEN` / `VERCEL_PROJECT_ID` / `WEB_DEPLOY_ENABLED`。原先基于 Vercel API 的受保护发布器保留但默认关闭；两种方式不要同时开启。

发布分支只存放运行包、静态托管配置及来源标记，不包含源码工作树、策划或研究。它仍在同一个**私有**仓库中；发布分支不合并回 main，不强推、不重置历史。旧发布提交可追溯。二进制会增加 Git 存储量，后续按真实增长另行优化，不能为清空间直接强推或抹掉历史。

根目录 `vercel.json` 刻意只输出 `hosting/placeholder`。这是防误部署措施，不是可以玩的网页版；真正运行文件只由成功检查生成到专用分支的 `public/`。Vercel 必须使用对应分支中的配置，不能保留导入时手动设置的占位输出覆盖值。

## 安全与验收边界

Git 分支同步成功只证明私有仓库中有已验证的运行包。GitHub token 无法读取或更改 Vercel 项目访问设置；Git 集成模式下由账号所有者完成保护设置，并另做真实 URL 验收，不声称程序已确认 Vercel 保护或已上线。

首次连接前没有已验证的线上网址。当前主干 `6553c8a` 的 Web 工作流 `38029987103` 已成功，取回原始证据确认 46 个真实 Chromium/Mesa 检查点通过；不是继续显示“主干检查仍在执行”。新流水线的执行结果按各次 Actions 与发布分支提交确认。

## 官方操作依据（2026-10-10 核查）

- [Vercel Git 导入与生产分支](https://vercel.com/docs/git)：原生 Git 集成、私有仓库权限、创建部署和生产分支。
- [Vercel Deployment Protection](https://vercel.com/docs/deployment-protection)：All Deployments 包括生产域名；Standard Protection 不包括生产域名。
- [Vercel 项目配置](https://vercel.com/docs/project-configuration)：由仓库配置静态构建与输出。
- [OpenAI 应用连接说明](https://help.openai.com/en/articles/11487775-connected-apps-in-chatgpt)：插件安装、服务账号连接、操作批准是不同状态，不保证特定聊天出现弹窗；本方案无需 ChatGPT 插件连接。
