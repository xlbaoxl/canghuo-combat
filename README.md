## 最新讨论方向：战前配置，战中自动演算

2026-10-13，作者明确转向：战前配置角色与技能用法，**双方出手顺序由系统演算，目标意图配置在每一门技能上，战中不再逐人选招、排人或点目标**。例如同一个灵气刃可配置优先选择血量最低或修为最低的目标。前轮提出的技能 CD 与按配置执行就绪技能的思路仍保留；整套连招是否连续执行、冷却时钟及九格阵位含义尚待确定。

详见[战前作战配置与自动演算](docs/战前作战配置与自动演算.md)，其中分别记录作者明确内容、讨论演变、助手候选和未决细则。**这是新的设计方向，不是已实现版本；现有 3.0.1 源码及线上试玩未因本次讨论改动。**旧文档中的手动战斗目标解释 3.0.1 基线，不覆盖作者最新方向。

## 3.0.1 基线的维护边界

以下用于维护和核验既有版本；新自动战斗的迁移冲突须在新方案中明确，不以本节否决作者新方向，也不借新方向之名暗改旧工程。

普通回合一次主动作；战机窗口允许多门合法施展。A/Z分离，W计全部自身窗口、R只计普通回合。普通成品CD=N≥1，W+CD恢复，格子与同源等待共同防止换法洗CD。

法宝保留**自动功效＋独立主动《催》**：禁止手动重放自动效果，不删除催动。功法联结人物凝练、系列与本法熟练，派生句不重复乘同一份成长。

训练营先选人物、再配装、再选镜像/预设。镜像难度同时调整基础实力和AI；纯策略对照另锁数值/配装。未扩大为完整养成、经济或探索。
