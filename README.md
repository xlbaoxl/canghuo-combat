## 当前规则要点

普通回合一次主动作，战机窗口多门合法施展；A/Z分离，W计全部自身窗口，R只计普通回合。普通成品CD=N≥1，W+CD恢复；格子和同源等待共同防止换法洗CD。

法宝保留**自动功效＋独立主动《催》**。要禁止的是手动重放自动那条，不是删除催动。功法效量联结人物凝练、系列与本法熟练，派生句不重复放大同一份成长。

训练营先选人物、再配装、再选镜像/预设。镜像难度同时改变基础实力和AI，纯策略实验另锁数值/配装。成长快照可以存在，不因此扩大成完整养成、经济或探索。

## 已认可但尚未实现

阵法作为延迟激活、分阶段功法：布阵到期才成阵，随后转持阵；龟甲阵的返盾基数等细节保留明确选项。结算内核的下一步是固定流程＋资格、修正、响应、时钟任务接口，把具体Buff行为从主流程中移出。

不是把这些文档上传就已经完成阵法和通用内核。实施按先迁工程、行为等价重构、再接入阵法的顺序，并保留失败与版本证据。
